# The productions of the YAML 1.2.2 specification

`yaml-1.2.2-productions.bnf` is the 211 productions of the specification, as it prints them
(`[#] name(n,c) ::= ...`), taken by script from `spec/1.2.2/spec.md` of
<https://github.com/yaml/yaml-spec>, which is (c) 2001-2021 the YAML Language Development Team
and licensed CC BY 3.0.  Only the productions are kept, as data for `bench/notation.sh`.
