bech32 corpus

bech32 (BIP-173) and bech32m (BIP-350), the address encoding of segwit: a human-readable part, a 1, then 5-bit symbols from a 32-character set, the last six of them a BCH checksum. Test data for the wire layer (tests/wire/segwit.hbnf reads the data part).

Status

Saved so the reference is in the repository. Nothing here is called yet. The checksum covers the human-readable part (bc, tb) as well as the data, and the segwit grammar reads only the data symbols, so it reads the checksum and does not check it. When the grammar can bring the human-readable part in, an %action calls bech32_decode from here, by its own name, and links segwit_addr.c.
