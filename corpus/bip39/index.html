BIP-39 corpus

The ten official word lists of BIP-39, "Mnemonic code for generating deterministic keys", unchanged, and the test that hbnf reads each of them with every word at its right index. Test data for the wire layer (RFCPLAN.md, step 7b), in the way corpus/rfc/ and corpus/posix/ are.

corpus/bip39/
  README.md        this file
  SHA256SUMS       the hash of every list, as taken
  wordlists/       english.txt ... spanish.txt, unchanged

cd wordlists && sha256sum -c ../SHA256SUMS checks them. grammars/bip39/ holds the same lists as hbnf include files, generated by tools/bip39_to_hbnf.py: one include "bip39/english.hbnf" gives a grammar bip39-word (the 2048 words) and bip39-space.

The index

A word's index is its line in the file, counted from 0, which is what BIP-39 writes into the 11 bits. Several lists are not in code point order (Spanish and French sort without accents, Japanese and the Chinese lists by reading), so the order of the file is the order, and nothing here sorts. hbnf writes the union of words longest first so that "act" is not taken for the start of "actor"; the values stay in the order of the list. tests/wire.sh parses every word of every list and checks its value against its line, and checks the English list against the eight published test vectors (the index of each word of a phrase, worked out from the entropy).
