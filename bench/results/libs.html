2026-11-04; glibc 2.41, gcc (Debian 14.2.0-19) 14.2.0, node 20.19.2, Python 3.13.5; -O2, the same sources and flags for every native library; hbnf acadd88. simdjson is its DOM API; the C++ and Rust libraries, Python, Node and the YAML parsers build their own value types, and hbnf builds the typed tree its grammar describes, except in the row that says %emit tape: that grammar writes a flat tape of 64-bit words and builds no tree. The XML parsers: expat 2.9.0, libxml2 2.12.7, pugixml 1.14, TinyXML-2 11.0.0, RapidXML 1.13 (Marcin Kalicinski's original, unmaintained since 2009), lxml 5.4.0, fast-xml-parser 5.11.2, sax 1.6.1; the first six are Debian packages, the Node ones are locked by bench/libs/node/package-lock.json. Every XML parser reads the same catalog and must find the same number of elements, of attributes (not counting xmlns declarations) and of non-blank bytes of text, references decoded, as ElementTree does (a driver that cannot count something does not, and a mismatch is a check failed row). The time is the parse call alone; the counting walks of the tree parsers come after the clock. expat, libxml2's SAX2 and sax build nothing, their handlers count, and the expat row that copies makes a small tree of names, attributes and text. pugixml and RapidXML parse the buffer in place, the others leave it alone. hbnf's XML grammar is measured twice: its typed tree and the same grammar under --layout=tape (the tape holds the elements, attributes and texts as 64-bit words; the driver counts from it), and that tree and that tape is the grammar's concrete syntax (a reference is a node and characters are not decoded). The last column is bench/xml-conformance.sh (bench/results/xml-conformance.md): of 34 documents that each break one well-formedness constraint of XML 1.0 (a forbidden control character, invalid UTF-8, ]]> or < where they may not be, two root elements, a bad character reference, a duplicate attribute, an undeclared entity ...), how many the parser refuses; marks a parser that does not refuse all of them or refuses a well-formed one; conforming parsers are left unmarked. Expat, libxml2, ElementTree and lxml refuse all of them (34 of 34). pugixml (8 of 34), TinyXML-2 (9 of 34) and RapidXML (7 of 34) are not conforming XML parsers: they check the structure of the tags and accept most content that XML forbids, and fast-xml-parser's parse (0 of 34) does not check well-formedness at all (the library has a separate XMLValidator, which this table does not time). hbnf's grammar refuses 27 of 34. A parser that skips checks does less work, so the time column is not like for like for the marked rows. The check is done once and kept: a parser is checked again only when its version, the case set or, for hbnf, its grammar or generator changes.
